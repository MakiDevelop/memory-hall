# Batch 2: usability (stacked on PR #6)

Synthetic data only. No merge, deployment, ingress change or real-data import is authorized by this document.

- **Schema errors that stop loops.** A bad `tools/call` returns `missing`, `unknown`, `wrong_type` (field names only, never values), a minimal `example`, and `attempt`. Counting is per verified principal + namespace + tool + error fingerprint and lives outside the MCP session, so reconnecting does not reset it. From the 3rd identical error (`RepeatGuard.threshold`) the result adds `stop_retrying: true` and a `reason`. Unknown tools and non-object arguments count too. A successful call of that tool clears the counter; the window is 10 minutes of quiet. Valid calls are never blocked. CAS and namespace denials come from the store, not the schema check, and are not counted.
- **Per-credential session quota.** `MAX_SESSIONS_PER_PRINCIPAL = 16` (global 128 stays). Idle expiry, `DELETE`, and revoked or changed credentials all free the slot on the next request.
- **Precheck.** MCP tool `precheck` (extended tools, all roles) and `mh pm precheck FILE [--path --summary --type --event-date]`. Scans text and every string metadata field with the write-time rules, stores nothing, calls no model, grants no exceptions. Returns `source_sha256`, `rule_version`, `safe`, and `field/category/line` findings.
- **Quotation rule (`safety-2`).** Previously any digit within 60 characters after 報價/quote was blocked. Now it needs an amount: currency marker before digits, digits followed by 元/萬/塊/NTD/TWD/USD/k, a thousands-separated number, or a bare number of four or more digits. Existing positive samples stay as regression tests; added negatives are listed in `test_batch2_usability.py`.
- **Cloud entrance test (not done here).** It needs mini2 and Cloudflare access, which this cloud session does not have. Needed from Maki: a synthetic Access service token, a test hostname/path that is not the production entrance, and an MCP client from the cloud container that can send `CF-Access-Client-Id/Secret` plus an app Bearer.
