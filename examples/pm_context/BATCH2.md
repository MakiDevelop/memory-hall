# Batch 2: usability (stacked on PR #6)

Synthetic data only. No merge, deployment, ingress change or real-data import is authorized by this document.

- **Schema errors that stop loops.** A bad `tools/call` returns `missing`, `unknown`, `wrong_type` (field names only, never values), a minimal `example`, and `attempt`. Counting is per verified principal + namespace + tool + error fingerprint and lives outside the MCP session, so reconnecting does not reset it. From the 3rd identical error (`RepeatGuard.threshold`) the result adds `stop_retrying: true` and a `reason`. Unknown tools and non-object arguments count too (JSON-RPC `error.data.stop_retrying` is a boolean). Guard keys are fixed-size digests; memory is capped at 4096 keys with least-recently-seen eviction and expired keys pruned on every record. Echoed unknown field names are capped at 20 × 64 characters. A successful call of that tool clears the counter; the window is 10 minutes of quiet. Valid calls are never blocked. CAS and namespace denials come from the store, not the schema check, and are not counted.
- **Per-credential session quota.** `MAX_SESSIONS_PER_PRINCIPAL = 16` (global 128 stays). Idle expiry, `DELETE`, and revoked or changed credentials all free the slot on the next request.
- **Precheck.** MCP tool `precheck` (extended tools, all roles) and `mh pm precheck FILE [--path --summary --type --event-date]`. Scans text and every string metadata field with the write-time rules, stores nothing, calls no model, grants no exceptions. Returns `source_sha256`, `rule_version`, `safe`, and `field/category/line` findings.
- **Quotation rule (`safety-3`).** Previously any digit within 60 characters after 報價/quote was blocked. Now it needs an amount: a currency marker before digits (NT$, NTD, TWD, USD, RMB, 新台幣, 台幣, 人民幣, 美金, $, ¥…; ASCII codes need a word boundary), digits followed by a currency or magnitude unit (元, 萬, 千, 仟, 億, 塊, 台幣…), a thousands-separated number, or a bare number of four or more digits that is not part of a date, version or identifier. Boundaries are ASCII-only, so "報價12000" counts. Existing positive samples stay as regression tests; added negatives and positives are in `test_batch2_usability.py`.
